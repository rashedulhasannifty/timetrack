# Slice 2.3b — Client activity capture & categorization (design)

**Date:** 2026-07-18
**Scope:** macOS client only (`apps/client-macos`). No contracts / API / DB / worker changes.
**Plan:** `docs/plans/phase-2-monitoring.md` § Slice 2.3, Step 1.
**PRD:** §6.3 (activity monitoring), §13 (window-title handling), §4.1 (ack gate).
**Engineering rules:** `CLAUDE.md` §1 (monitoring ethics — non-negotiable), §3 (client boundaries).

---

## 1. Goal

The macOS client samples keyboard/mouse **event counts** (never content) per fixed interval,
samples the frontmost app (and, best-effort, the window title), computes an **activity %**,
categorizes the sample `PRODUCTIVE | UNPRODUCTIVE | NEUTRAL` **client-side** from the admin
policy lists, buffers samples durably, and drains them in batches to the already-shipped
`POST /activity-samples/batch` ingest endpoint (2.3a).

**Done when:** while a user is tracking on an acknowledged, online policy, activity samples are
produced each interval, categorized, buffered, and uploaded in batches; window titles are
handled per `captureWindowTitles` and never logged; no capture happens on a stopped clock, a
closed gate, or the offline-marker path; sign-out cannot leak one user's samples to the next.

## 2. What already exists (do not rebuild)

- **Contracts (2.3a, shipped):** `ActivitySampleSchema` (`{ id, timestamp, appName≤200,
windowTitle≤120|null, activityPct 0–100 int, category default NEUTRAL }`), `ActivityBatchSchema`
  (`{ samples: [...] }`, 1–500), `ACTIVITY_SAMPLE_INTERVAL_SECONDS = 60`. The Swift client
  **mirrors the interval by convention** (it cannot import the TS file).
- **API (2.3a, shipped):** `POST /activity-samples/batch` — JSON, idempotent upsert on the
  client-minted UUIDv7 (`id`), ≤500 samples, attribution by **token** (no `userId` in the payload).
- **Client `EventCounter`** exists today as a dead manual accumulator (`recordKeyEvent()` /
  `recordPointerEvent()` — nothing feeds it). This slice **repurposes** it (§4.1); no dead API left.
- **Client capture spine to mirror:** `ScreenshotScheduler` (capture-gated self-scheduling timer),
  `ImageBufferStore` (durable per-record buffer), `ScreenshotSyncEngine` (batch-ish drain +
  backoff + age/count prune), and the `AppDelegate` install (`startScreenshotCaptureIfEnabled`) +
  sign-out teardown (`flushAndClearBuffer`). This slice follows those patterns exactly.

**Scope guard:** if this slice edits `packages/contracts`, `apps/api`, `packages/db`, or
`apps/worker`, it has drifted — stop and re-scope. The only non-`apps/client-macos` artifacts are
this spec and its plan under `docs/`.

## 3. Product decisions (locked)

1. **Activity % = sub-bucket presence ratio.** The 60s interval is split into **12 sub-buckets of
   5s**. A bucket is _active_ if `keyΔ + pointerΔ > 0` across it. `activityPct = round(activeBuckets
/ 12 × 100)`. (Industry-standard "active seconds" model; robust to typing speed.)
2. **Sample only while tracking.** Sampling runs only while `isTracking()` **and** the `AckGate` is
   open — mirrors "no screenshots on a stopped clock." A stopped clock produces no samples and
   triggers no policy fetch.
3. **Categorize on app + site.** Host (site) match wins when a host is resolvable; otherwise fall
   back to app-name match; otherwise `NEUTRAL`.
4. **Site host is read from the browser URL via AppleScript** (Automation / Apple Events
   permission), for a known browser set. When the grant is absent, the frontmost app is not a known
   browser, or the read fails → `host = nil` → app-only categorization. Never blocks a sample.

### 3.1 Ethics boundary (CLAUDE.md §1) — explicit

- **Event counts only, no content.** Counts come from `CGEventSource.counterForEventType`, which
  returns an aggregate counter maintained by the window server. There is **no code path** that taps,
  reads, or inspects a key/pointer event's content — by construction, not by convention.
- **The browser URL is read transiently, client-side, solely to derive `category`.** The raw URL and
  the derived host are **never stored, transmitted, or logged.** The transmitted `ActivitySample`
  carries only `appName`, `windowTitle` (subject to policy), `activityPct`, `category`. The host is
  **not** written into `windowTitle`.
- **`windowTitle` honors policy.** Captured only if `captureWindowTitles == true`, truncated to 120
  chars, else `null`. `windowTitle` is already on the Pino redact list server-side; the client never
  logs it either.
- **No capture without ack, ever.** Sampling installs only on the online `!ackRequired` branch,
  only through `AckGate`, and re-checks the gate each tick. The offline AckMarker path (manual
  tracking only) never opens sampling.

## 4. Components (all in `apps/client-macos/Sources/TimeTrack/Activity/` unless noted)

Each unit has one purpose, a narrow interface, and pure logic split from side effects so it is
unit-testable without a running app.

### 4.1 `EventCounter` (repurposed)

Wraps the content-free system counter. Replaces the dead manual accumulator.

```swift
protocol InputCounting { func snapshot() -> (keys: UInt64, pointer: UInt64) }

final class EventCounter: InputCounting {
    // keys   = keyDown
    // pointer = mouseMoved + leftMouseDown + rightMouseDown + otherMouseDown
    //           + leftMouseDragged + rightMouseDragged + scrollWheel
    func snapshot() -> (keys: UInt64, pointer: UInt64)  // reads CGEventSource cumulative counters
}
```

- Reads `CGEventSource.counterForEventType(.combinedSessionState, eventType:)` — verified to
  return live cumulative counts with **no** Input-Monitoring / Accessibility prompt (same family as
  `WorkspaceObserver.secondsSinceLastEventType`). Autorepeat key events are not counted (per the
  system counter's documented behavior).
- Counters are **cumulative since login**; callers diff snapshots across sub-buckets. Monotonic
  `UInt64`; the sampler computes deltas with wrap-safe subtraction.

### 4.2 `ActivityRateMeter` (pure)

Pure activity-% computation, separated from timing so it is fully unit-tested.

```swift
struct ActivityRateMeter {
    let buckets: Int            // 12
    // Feed one (keys,pointer) snapshot per sub-bucket; returns 0–100 once `buckets` are collected.
    mutating func addBucket(delta: (keys: UInt64, pointer: UInt64))
    func activityPct() -> Int   // round(activeBuckets / buckets * 100), clamped 0…100
}
```

### 4.3 `AppSampler`

Frontmost-app + best-effort window title. Side-effecting; wrapped behind a protocol for tests.

```swift
protocol AppSampling { func sample(captureWindowTitles: Bool) -> (appName: String, windowTitle: String?) }
```

- `appName` = `NSWorkspace.shared.frontmostApplication?.localizedName` (fallback `"Unknown"` if nil).
- `windowTitle`: only if `captureWindowTitles`, via `CGWindowListCopyWindowInfo`
  (`kCGWindowName` for the frontmost app's front window; rides the existing Screen Recording grant).
  Truncated to 120 chars (grapheme-safe). `nil` if policy is off, the grant is absent, or no title.

### 4.4 `SiteResolver`

Resolves the front browser's active-tab **host** for categorization only.

```swift
protocol SiteResolving { func currentHost() -> String? }   // nil ⇒ app-only categorization

final class AppleScriptSiteResolver: SiteResolving {
    // Known browsers by bundle id → AppleScript to read the active-tab URL:
    //   Safari:            URL of current tab of front window
    //   Chromium family:   URL of active tab of front window   (Chrome, Edge, Brave, Arc, Chromium)
    // Returns host (lowercased, leading "www." stripped) or nil.
}
```

- Runs AppleScript via `NSAppleScript` against the **frontmost** app only, and only when that app's
  bundle id is in the known-browser set (never scripts arbitrary apps).
- **Automation (Apple Events) permission:** `NSAppleEventsUsageDescription` in the app Info.plist;
  the first read triggers the per-target TCC prompt ("TimeTrack wants to control <Browser>").
  Denied / error / timeout → `nil`. The URL is discarded after the host is extracted; only the host
  (transiently) reaches the `Categorizer`.
- Host extraction is a pure helper (`SiteResolver.host(from: url)`) so it is unit-tested without
  AppleScript.

### 4.5 `Categorizer` (pure)

```swift
struct Categorizer {
    let productiveApps: [String]     // from policy
    let unproductiveApps: [String]   // from policy
    // Host wins when present; else app name; else NEUTRAL. Case-insensitive, trimmed.
    // A term matches a host by suffix (e.g. "youtube.com" matches "m.youtube.com"); an app by equality.
    func category(appName: String, host: String?) -> Category   // PRODUCTIVE|UNPRODUCTIVE|NEUTRAL
    enum Category: String { case productive = "PRODUCTIVE", unproductive = "UNPRODUCTIVE", neutral = "NEUTRAL" }
}
```

- Precedence when a term appears in both lists: **UNPRODUCTIVE wins** (fail toward flagging, matches
  the conservative posture elsewhere). Documented and tested.

### 4.6 `ActivitySample` (client payload)

`Codable` struct that encodes **exactly** the server contract (extra keys rejected server-side by
strict parsing):

```swift
struct ActivitySample: Codable {
    let id: String            // client-minted UUIDv7 (idempotency key)
    let timestamp: String     // ISO-8601 (interval end)
    let appName: String
    let windowTitle: String?
    let activityPct: Int      // 0…100
    let category: String      // Category.rawValue
}
```

### 4.7 `ActivitySampleStore` (durable buffer)

Own file-backed buffer under Application Support, mirroring `ImageBufferStore`/`BufferStore`
(atomic write-temp-then-rename, FIFO by filename-encoded millis, `.tmp-` sweep on init, age/count
prune, `clear()`). One JSON file per sample. Kept separate from the time-entry `BufferStore` (its
drain is one-POST-per-record; activity is batched).

```swift
protocol ActivitySampleBuffering {
    func enqueue(_ sample: ActivitySample)
    func take(limit: Int) -> [ActivitySample]     // FIFO
    func remove(ids: [String])
    func prune(olderThan: TimeInterval, maxCount: Int)
    func clear()
}
```

### 4.8 `ActivitySampleUploader`

Batch JSON upload. Reuses `UploadResult` + `TimeEntryUploader.classify`.

```swift
protocol ActivitySampleUploading { func upload(_ samples: [ActivitySample]) async -> UploadResult }

final class ActivitySampleUploader: ActivitySampleUploading {
    // POST <baseURL>/activity-samples/batch, body { "samples": [...] }, bearer token.
    // 401 → forceRefresh → retry once → classify. Not a capture path (no AckGate).
    // Pure body builder is unit-tested; async orchestration is build-verified.
}
```

### 4.9 `ActivityBatchSyncEngine`

Self-scheduling drain (mirrors `ScreenshotSyncEngine`) but **batch-oriented**: each pass prunes,
takes ≤500 samples, POSTs **one** batch, and on:

- `success` → `remove(ids:)` the whole batch, reset backoff, continue to next batch;
- `permanent` → `remove(ids:)` the batch (a poison batch can't wedge the queue);
- `transient` / `authFailed` → stop this cycle, caller backs off.

Not a capture path → safe on both online and offline-marker `becomeReady()` paths. `finishInFlight()`
join point for sign-out. Age/count prune each cycle (`maxAge = 7d`, `maxCount = 5000`).

### 4.10 `ActivitySampler` (capture-gated orchestrator)

The one capture path in this slice. Mirrors `ScreenshotScheduler` precisely:

- Self-scheduling `Timer` on the 60s interval; `start()`/`stop()`/`startCycle()`/`finishInFlight()`.
- Each cycle: `guard isTracking()` **before** the gate → `AckGate.withCaptureAllowed { … }` →
  drive 12×5s sub-buckets (diff `EventCounter` snapshots into `ActivityRateMeter`) → at interval
  end sample app (`AppSampler`), host (`SiteResolver`), categorize (`Categorizer`), mint UUIDv7,
  enqueue into `ActivitySampleStore`, then kick `ActivityBatchSyncEngine.syncNow()`.
- Gate closed / error → skip the interval (fail-safe). Never enqueues on a closed gate.
- Sub-bucketing runs **inside** the gated block; if the gate is closed at interval start the whole
  interval is skipped (no partial sample).

## 5. Policy decode (client-only)

Extend `EffectivePolicy.Settings` (in `Policy/PolicyClient.swift`) to decode three fields the JSON
already carries (extra keys are ignored by `Decodable`; these just start being read):

```swift
let captureWindowTitles: Bool
let productiveApps: [String]
let unproductiveApps: [String]
```

`Decodable` requires present keys, so provide safe decoding for legacy/partial policy JSON: default
`captureWindowTitles` to `true`, `productiveApps` / `unproductiveApps` to `[]` when absent (matches
the server `TeamSettingsSchema` defaults). Update `PolicySettingsDecodeTests` accordingly.

There is **no** `activityEnabled` flag in `TeamSettings`; activity monitoring is the baseline for an
acknowledged policy. Sampling therefore installs whenever capture is allowed (ack + online) — it is
not conditioned on a settings flag, unlike screenshots (`screenshotsEnabled`).

## 6. AppDelegate wiring

Additive; follows the screenshot install + teardown exactly.

1. **Install (capture path).** New `startActivityCaptureIfEnabled(_ policy:)`, called from
   `proceedToPolicy`'s online `!ackRequired` branch **only** (right after
   `startScreenshotCaptureIfEnabled`). It goes through `ackGate.withCaptureAllowed` and calls
   `installActivityCapture(policy:)` on the main thread. Idempotent (`guard activitySampler == nil`).
   Builds `EventCounter`, `AppSampler`, `AppleScriptSiteResolver`, `Categorizer` (from
   `policy.settings.productiveApps/unproductiveApps`), `ActivitySampler`, and the
   `ActivityBatchSyncEngine` (started in `startSyncIfNeeded`, like `screenshotSync`).
2. **Sync start.** In `startSyncIfNeeded`, also construct and `start()` the
   `ActivityBatchSyncEngine` with `ActivitySampleStore.shared` + `ActivitySampleUploader`. Not a
   capture path → safe on both branches.
3. **Sign-out teardown.** In `flushAndClearBuffer` (and the `stopAutoTracking`/timer-stop ordering
   that precedes it), add the activity path with the **same ordering guarantees** as screenshots:
   stop the sampler timer → `finishInFlight()` join (a cycle suspended mid-AppleScript must not
   enqueue post-clear) → stop the sync engine → best-effort final `syncNow()` on the still-valid
   token → `ActivitySampleStore.shared.clear()`. This is the cross-user-integrity invariant
   (samples are token-attributed); it is **not** optional.
4. **Permission surfacing.** Screen Recording is already requested for screenshots; window titles
   ride that grant with no new prompt. Automation is requested lazily by the first `SiteResolver`
   read; a denial degrades to app-only and does not surface a blocking warning (activity still
   flows). (No new menu-bar warning state in this slice.)

## 7. Error handling & degradation

| Condition                                                        | Behavior                                                       |
| ---------------------------------------------------------------- | -------------------------------------------------------------- |
| AckGate closed / policy unavailable at interval start            | Skip the interval; no enqueue; no partial sample.              |
| Not tracking                                                     | No cycle runs; no policy fetch.                                |
| `captureWindowTitles == false` or Screen Recording not granted   | `windowTitle = null`; sample still produced.                   |
| Automation not granted / non-browser / AppleScript error/timeout | `host = nil` → app-only category; sample still produced.       |
| Upload transient (network / 5xx / 408 / 429)                     | Keep batch, back off, retry.                                   |
| Upload permanent 4xx (non-401)                                   | Drop that batch (no poison wedge).                             |
| Upload 401 after one refresh                                     | `authFailed` → stop cycle, back off.                           |
| Sign-out mid-cycle                                               | Join in-flight, final drain on valid token, then clear buffer. |
| Buffer growth while offline                                      | Age prune (7d) + count prune (5000) each sync cycle.           |

## 8. Testing (XCTest — pure logic; async orchestration build-verified)

- **`ActivityRateMeter`:** all-idle → 0%; all-active → 100%; 7/12 → 58%; rounding; clamp.
- **`EventCounter`:** wrap-safe delta on `UInt64` snapshots (inject a fake counter source).
- **`Categorizer`:** host-wins-over-app; app fallback when host nil; NEUTRAL default; case-insensitive
  - trimmed; host suffix match; UNPRODUCTIVE precedence on overlap.
- **`SiteResolver.host(from:)`:** scheme/path/query stripped; `www.` stripped; lowercased; invalid → nil.
- **`AppSampler`:** window title truncated to 120; `nil` when `captureWindowTitles == false` (fake grabber).
- **`ActivitySampleUploader`:** batch body shape `{ samples: [...] }`; `classify` mapping (reused).
- **`ActivitySampleStore`:** FIFO order; atomic enqueue; `remove(ids:)`; age/count prune; `clear()`;
  `.tmp-` sweep.
- **`ActivityBatchSyncEngine.syncNow()`:** success removes whole batch + resets backoff; permanent
  drops batch; transient stops early and returns backed-off; multi-batch continuation.
- **`ActivitySampler`:** `guard isTracking()` before gate (no gate call when stopped); closed gate →
  no enqueue; one full cycle enqueues exactly one categorized sample (fakes for gate/app/site/store).
- **Sign-out teardown:** ordering — sampler stopped and joined before `clear()`; a cycle completing
  after `stop()` does not enqueue into a cleared store.
- **`PolicySettingsDecodeTests`:** new fields decode; legacy JSON without them uses safe defaults.

**Gate to claim done:** from `apps/client-macos`, with the Xcode toolchain,
`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build && swift test` green. Repo

## 10. Definition of Done

- [ ] `ActivitySampler` installs only on the online `!ackRequired` branch, only via `AckGate`,
      re-checks the gate each tick, and `guard isTracking()` before the gate.
- [ ] Activity % is the 12×5s sub-bucket ratio; samples carry app, policy-gated window title,
      activity %, and a client-side category (app + site).
- [ ] The browser URL is read only to derive the category and is never stored/transmitted/logged;
      `windowTitle` honors `captureWindowTitles`, truncated to 120, never logged.
- [ ] Samples buffer durably and drain in ≤500 batches to `POST /activity-samples/batch`; transient
      backs off, permanent drops the batch, 401 stops after one refresh.
- [ ] Sign-out stops + joins the sampler, final-drains on the valid token, then clears the buffer —
      no cross-user leakage.
- [ ] `EventCounter`'s dead manual API is gone (repurposed); no stubs left on the done path.
- [ ] `swift build && swift test` green; repo gate green; no non-client source touched.
